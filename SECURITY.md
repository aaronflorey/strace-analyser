# Security Policy

## Supported Versions

Only the latest release is supported with security fixes.

## Reporting a Vulnerability

Please report security issues privately through GitHub Security Advisories:

https://github.com/aaronflorey/strace-analyser/security/advisories/new

If that path is unavailable, open an issue asking for a secure contact channel and do not include sensitive exploit details.

## Response Expectations

- Initial triage target: within 7 days
- Status updates: at least weekly while a fix is in progress
- Coordinated disclosure: after a fix is released or mitigation guidance is available
